# Code of conduct

## Our commitment

We want a project where all people can take part without harassment. We respect different experience levels, backgrounds, and opinions.

## Expected behavior

- Be professional and direct.
- Discuss the code and the task, not the person.
- Give clear technical reasons for a decision.
- Accept a different opinion when the evidence supports it.
- Help a new contributor use the project.
- Use inclusive language.

## Unacceptable behavior

- Insults, threats, or personal attacks.
- Harassment in public or private.
- Discriminatory language or images.
- Publication of private data without permission.
- Deliberate disruption of a discussion or a review.
- Retaliation against a person who reports a problem.

## Scope

This code applies to repository issues, pull requests, discussions, and project chat. It also applies when a person speaks for the project in public.

## Report a problem

Do not open a public issue for a conduct problem. Send a private report to a maintainer through the GitHub profile of the repository owner.

Give these items:

- A description of the incident.
- The date and the location.
- The people involved.
- Links or screenshots, if possible.
- The result that you need.

A maintainer will review the report and keep it private. The maintainer will try to answer within seven days.

## Enforcement

A maintainer can take these steps:

1. Give a private warning.
2. Remove a comment or a change.
3. Block the person from the repository.
4. Report the incident to the hosting platform.

The maintainer will select the smallest step that prevents more harm. The maintainer will not take part in a decision about a report against them.
