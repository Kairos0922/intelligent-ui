# Support

## Documentation

Read these documents first:

- [README.md](README.md) for install and quickstart.
- [SDK.md](SDK.md) for the core API.

## Questions

Use the GitHub question form for a question about install, configuration, or use. Give the package version, the host, and the steps that you tried.

## Defects and features

Use the GitHub issue forms for a defect or a feature request. Do not use an issue for a security problem.

## Security

Read [SECURITY.md](SECURITY.md) and use GitHub Security Advisories.

## Response time

The maintainers are volunteers. They will try to answer a new issue within seven days. A complex problem can take longer.

## Commercial support

The project does not offer commercial support.
